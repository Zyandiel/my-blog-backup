将博客当前使用的远程 WOFF2 字体缓存到 WordPress 上传目录，提前预加载，并减少无缓存访问时的全站字体跳变。

== 功能 ==

1. 激活时自动把当前远程字体保存到 wp-content/uploads/dieyu-font-accelerator。
2. 前台从你自己的网站加载字体，不再让每位访客直接连接 jsDelivr。
3. 在页面顶部预加载字体，让下载更早开始。
4. 默认使用“完整显示模式”：本地字体准备好后，当前页面会全部换上字体，不需要再次刷新。
5. 可选择停止加载 Argon 自带的 Google Fonts。
6. 提供字体状态和一键重新下载功能。

== 安装 ==

1. 在 WordPress 后台进入“插件 → 安装插件 → 上传插件”。
2. 上传本插件 ZIP，安装并启用。
3. 进入“设置 → 蝶语字体加速”。
4. 确认“本地字体状态”为“已成功缓存”。
5. 保持“完整显示模式”和“提前加载”即可。

如果激活时自动下载失败，请在设置页点击“重新下载并缓存字体”。

== 关于原来的 CSS ==

请暂时保留 Argon 主题选项中原来的字体 CSS。插件会在前台用本地字体规则覆盖它；停用插件后，原来的字体外观会自动恢复。

== 三种显示方式 ==

完整显示模式（推荐）：本地字体加载完成后，当前页面会全部换上自定义字体，不需要再次刷新。

折中模式：给字体一个较短的加载机会，过慢时使用系统字体。

系统字体优先模式：无缓存时可能一直使用系统字体，直到下次刷新。

== 字体文件说明 ==

插件 ZIP 不包含第三方字体文件。激活插件时，由你的网站按照设置中的来源地址下载字体并保存到 WordPress 上传目录。请确保你对所配置字体拥有相应的使用权限。
