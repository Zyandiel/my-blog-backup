# 用户身份标签

这是一个可直接安装的 WordPress 插件。它建立独立的“用户身份标签”，不会复用文章标签，也不会改变文章的标签、归档或查询。

## 最快使用方法

1. 上传并启用 `user-identity-labels.zip`。
2. 进入“用户 → 身份标签”，创建“摄影师”“认证成员”等身份。
3. 在同一页面的“分配给我的账号”中勾选并保存；其他账号可到“用户 → 编辑用户”分配。新建标签默认同时分配给当前账号。
4. 后台用户列表会在数字 ID 下方直接显示这些标签。
5. 前台用“用户身份标签”区块，或把 `[identity_labels]` 放在主题的用户 ID/昵称下面。

如果主题已有一个 ID 元素，在“显示设置”填入其唯一 CSS 选择器（例如 `.profile-header .user-id`），再选择“当前个人资料用户”“当前文章作者”或“当前登录用户”。插件只处理选择器匹配到的第一个元素，避免在成员列表中把同一个人的标签复制给其他人。

使用 Argon 主题时无需填写选择器：在“显示设置”启用“Argon 主题侧栏头像/昵称下方”，并选择侧栏资料卡代表的 WordPress 用户。标签会自动显示在侧栏昵称下、文章统计上方。

## 前台调用

```text
[identity_labels]
[identity_labels user_id="12"]
[identity_labels context="current"]
[user_identity]
```

主题 PHP 模板：

```php
<?php uil_user_identity_labels( get_the_author_meta( 'ID' ) ); ?>
```

需要取得 HTML 而不是直接输出：

```php
<?php
$html = uil_get_user_identity_labels( $user_id );
echo wp_kses( $html, uil_plugin()->get_allowed_label_html() );
?>
```

## 显示规则

- 作者归档页：显示被查看作者的标签。
- 单篇文章：显示文章作者的标签。
- BuddyPress 个人页：显示当前个人资料所属用户的标签。
- 其他页面：没有更明确的作者上下文时，才使用当前登录用户。
- 用户没有身份标签时，不输出空容器。
- 显式传入不存在的 `user_id` 时直接返回空，不会误显示其他人的标签。

## 权限与数据

- 标签库和显示设置：需要 `manage_options`。
- 默认只有管理员可以分配标签。
- 可选允许用户给自己选择已有标签，但不能创建标签或修改他人。
- 标签定义保存在 `uil_identity_labels` 站点选项中。
- 分配结果以站点级用户选项保存；多站点之间不会互相覆盖。
- 停用或普通卸载默认保留数据。
- 如需卸载时彻底清理，在 `wp-config.php` 中加入：

```php
define( 'UIL_DELETE_DATA_ON_UNINSTALL', true );
```

然后再从 WordPress 后台删除插件。

## 主题兼容说明

WordPress 核心没有统一的“用户 ID/昵称下方”前台挂载点。插件采用四层兼容方式：

1. 自动适配作者归档与核心“文章作者名称”区块。
2. 对 BuddyPress、bbPress 使用其公开钩子。
3. 自定义且唯一的 CSS 选择器定位任意主题元素，并明确标签所属用户来源。
4. 区块、短代码和模板函数作为精确兜底。

对于定制会员主题，最可靠的方式是找到 ID 元素的 CSS 类并填入设置，或直接把区块/短代码放到 ID 下面。若手动放置区块/短代码，请关闭同一位置的自动显示开关，以免重复。
