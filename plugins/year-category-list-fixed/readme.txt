=== Year Category List ===
Contributors: site-customization
Tags: categories, shortcode, year
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.1
License: GPLv2 or later

Adds the [year_category_list] shortcode.

The shortcode:

* selects four-digit top-level post categories;
* sorts years by name in natural descending order;
* displays all descendants under the matching year;
* links every category name to its category archive;
* retains WordPress category-list ul/li classes so the active theme can style it.

Use a Shortcode block containing:

[year_category_list]
