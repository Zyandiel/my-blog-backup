从后台语录库中随机抽取一句博客标语，以逐字打字和闪烁光标效果显示。

== 功能 ==

* 后台语录库，每行一句，最多 300 句
* 每次打开页面时在浏览器端随机选择，兼容页面缓存
* 只渲染语录库里的文字，不读取或搜索主题中的原始文案
* 通过 Argon 官方标题接口直接接管 Banner 标题
* Argon 适配启用时自动避免主题自带打字动画冲突
* 提供 [butterfly_quote] 短代码，直接放入目标位置
* 可选 CSS 展示位，适配无法插入短代码的主题横幅
* 可调整打字速度、开始延迟、标点停顿和光标字符
* 光标仅在打字过程中显示，完成后自动消失
* 支持动态加载的页面内容

== 安装 ==

1. 在 WordPress 后台进入“插件 → 安装插件 → 上传插件”。
2. 上传本插件 ZIP 并启用。
3. 进入“设置 → 蝶语打字机”。
4. 每行填写一句语录并保存。
5. 使用 Argon 主题时，保持“直接把随机语录显示在 Argon 的 Banner 标题位置”开启即可，无需修改主题设置。

== 展示方式 ==

使用 Argon 主题时，插件通过主题提供的 argon_banner_title_html 接口直接显示随机语录。停用插件后，Argon 原来的 Banner 标题会恢复。

其他主题可以在目标位置使用 [butterfly_quote]，或者预留一个空元素并填写它的 CSS 选择器。插件不会根据某一句原文进行查找。
