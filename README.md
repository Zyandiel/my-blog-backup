# My Blog

Source files of my WordPress blog.

This repository contains my customized WordPress theme,
plugins and media assets.

The database is not included because it contains private content.


## Tech Stack

- WordPress
- PHP
- MySQL
- Nginx
- Argon Theme


## Structure

- themes: WordPress themes
- plugins: WordPress plugins
- uploads: media files

Database files are not included because they contain private content.


## Deployment

To restore this blog:

1. Install WordPress
2. Install required plugins
3. Copy themes into wp-content/themes
4. Copy plugins into wp-content/plugins
5. Restore database backup
